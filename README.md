# チキンレース(クイズ大会用 対戦ツール)

クイズに正解した人がテーブルにボールを転がし、最終問題の終了時に対辺(奥の辺)へ最も近いボールを残した人が勝つ対戦ゲームです。
出題と会話は通話ツールで行い、このツールは正誤入力・投球・ボールの物理計算・進行・保存を担当します。

- 最大 12 人の個人戦。ボールはプレイヤーごとの色と名前の頭文字で区別します。
- インストール不要。ブラウザで `host.html`(親)と `player.html`(子)を開くだけです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入口(親・子の選択) |
| `host.html` | 親(司会)用。進行・正誤入力・設定・履歴 |
| `player.html` | 子(プレイヤー)用。投球と観戦 |
| `firebase-config.js` | オンライン対戦用の接続設定(要記入) |
| `js/`, `css/` | プログラム本体 |

## まず試す(設定不要のお試しモード)

`firebase-config.js` が未設定のあいだは「お試しモード」で動きます。**同じブラウザの別タブ同士**でだけ対戦できます。

1. このフォルダで簡易サーバーを起動する。

   ```bash
   python -m http.server 8765
   ```

2. `http://localhost:8765/host.html` を開き「新しいルームを作成」。
3. 「参加URLをコピー」で得た URL を同じブラウザの別タブで開き、名前を入れて参加。

## オンライン対戦の準備(親が一度だけ行う)

中継に Firebase Realtime Database(無料枠)を使います。参加者側の準備は不要です。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成する。
2. 「構築 > Realtime Database」でデータベースを作成する。
3. 「ルール」を次の内容にして公開する。

   ```json
   {
     "rules": {
       "rooms": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }
   ```

4. 「プロジェクトの設定 > マイアプリ」でウェブアプリを追加し、表示される `firebaseConfig` を `firebase-config.js` の `null` と置き換える(`databaseURL` が必須)。
5. フォルダ一式を配布する。方法は次のどちらでも構いません。
   - **Web に置く(推奨)**: GitHub Pages などの静的ホスティングにアップロードし、親は `host.html`、子は親が配る参加 URL を開く。
   - **zip で配る**: フォルダを zip で渡し、子は `player.html` を開いてルームコードを入力する。

注意: 上のルールは、ルームコードを知っている人なら誰でも読み書きできる簡易な設定です。関係者内での利用を想定しています。大会後は親画面の「ルーム > ルームを閉じる」でデータを削除してください。

## 遊び方

### 親

1. `host.html` でルームを作成し、参加 URL(またはルームコード)を配る。
2. 「進行」タブで参加者を確認する。並び順が**事前順位**(上ほど上位)。▲▼ やシャッフルで変更可。通話のみの参加者は名前を手入力で追加し、代理投球できます。
3. 「ゲーム開始」を押すと第1問の正誤入力画面になる。出題中もこの画面で待機します。
4. 正解者を ○ にして「確定して投球へ」。正解者にボールが 1 個ずつ与えられ、**順位の低い人から順に**投球します。
5. 全員が投げ終わり、すべてのボールが止まると自動で次の問題の正誤入力画面へ進みます。最終問題の後は結果画面になります。

投球中にできること:
- **代理投球**: 番のプレイヤーの代わりに親が盤面で投げる。
- **パスさせる**: 番のプレイヤーの投球を飛ばす(ボールは無効)。

### 子

1. 参加 URL を開き、名前を入れて参加する。再読み込みやタブを閉じた後は「参加済みのプレイヤーとして再開する」から戻れます。
2. 自分の番になったら、盤面を押したまま**下に引っ張って離す**と発射。
   - 押した位置の左右が発射位置、引っ張る向きの反対が発射方向、引っ張る長さがパワーです。
   - パワーはバーだけで表示し、数値は出しません(同じ強さを再現できないようにするため)。
   - ほとんど引かずに離すと取り消しになります。
3. 前の人のボールが止まるのを待つ必要はありません。番が回ってきたらすぐ投げられます。

## ルール(実装内容)

- **順位**: ①盤上に残っている自分のボールのうち最も対辺に近いものの距離が小さい順 ②事前順位。盤上にボールがない人は、ボールがある人より下位。
- **落下**: ボールの中心がテーブルの辺(四辺とも)を越えると落下し、無効になります。他人のボールに当てて落としても構いません。
- **投球順**: 正誤を確定した時点の順位で決まり、その問題のあいだは変わりません。
- **勝敗**: 最終問題の終了時の順位 1 位が優勝。盤上にボールが 1 つもない場合は事前順位で決まります。

## 設定(試合中でも変更可)

親画面の「設定」タブで変更し「適用」を押すと、その時点から全員に反映されます。

| 項目 | 既定値 | 説明 |
|---|---|---|
| 問題数 | 6 | 最終問題の番号 |
| 摩擦(減速度) | 260 mm/s² | 大きいほど早く止まる |
| 反発係数 | 0.9 | ボール同士の跳ね返り(0〜1) |
| 最大初速 | 900 mm/s | パワー 100% のときの速さ |
| 最大発射角度 | 60 度 | 正面から左右に傾けられる角度 |
| 最短投球間隔 | 1 秒 | 前の投球から次の発射までの最短時間。早く投げた場合はこの時間まで待ってから発射されます |
| ボール半径 | 18 mm | |
| テーブル幅・奥行 | 600 × 1000 mm | |
| 発射位置 | 200 mm | 手前の辺から発射ラインまでの距離。大きいほど下に引っ張る余白が増える |
| 最大パワーになる引き距離 | 320 mm | 小さいほど短い引きで強く飛ぶ(盤面上の長さ) |
| 照準ガイドの長さ | 160 mm | 0 にするとガイド線なし |

設定画面の下に「パワー 100% で転がる距離」と「対辺ちょうどで止まるパワー」の目安が表示されます。

## 保存と巻き戻し

- 親のブラウザに自動保存されます。親が再読み込みしても、同じルームをそのまま再開できます。
- 「履歴」タブに、各問の正誤入力前・正誤確定時・各投球(パス)の直前が自動で記録されます。「戻す」を押すとその時点に戻り、全員の画面に反映されます。設定は現在の値のままです。
- 連続投球で他のボールが動いている最中の投球前に戻した場合は、動いていたボールがその時点から動き出します。
- 「JSONに書き出す / 読み込む」で、ゲームの状態と履歴をファイルに保存・復元できます(別の PC での再開用)。

## 注意点

- 物理計算は親のブラウザで行います。**親のタブは表示したままにしてください**(裏に回すと進行が遅れることがあります)。
- 子の画面は通信の揺れを吸収するため、親より約 0.25 秒遅れて再生されます。
